# Assignment #2 Analyzing Connections Between SWE and Streamflow in Alaska

The homework 2 folder in this repository downloads and analyzes streamflow data for the Little Susitna River near Palmer, Alaska. SNOTEL data is also downloaded for the Independence Mine site within the same watershed.

The scripts folder contains important resources for downloading data (get_usgs_data.py and get_snotel_data.py) and exploring connections between peak SWE and streamflow (snotel_usgs_analysis.py). The mapping_AOI.py brings in data from streamstats, to visualize the basin. (on the homework2 branch)


# Assignment #1 Analysis of Streamflow Data in Utah

The homework1 folder in this repository downloads and analyzes streamflow data near the Uinta Basin in Utah. The download_data.py has specific instructions for downloading data directly from the USGS API. (on the homework1 branch)

The EDA.py performs the data analysis, exploring resampling of discharge data, and comparison of wet and dry years. All required packages can be obtained through utilizing the homework1.yml
